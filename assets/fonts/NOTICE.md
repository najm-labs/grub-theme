# Third-party fonts

## Amiri (`amiri.woff`)
Used only to render the Arabic verse images at build time.
Licensed under the SIL Open Font License 1.1 - see `AMIRI-LICENSE.txt`.

## Victor's Pixel Font (`victor_pixel_21.pf2`, `victor_pixel_32.pf2`)
The pixel font used for the boot menu. Larger sizes are derived from these
files by `tools/pf2.py`.
